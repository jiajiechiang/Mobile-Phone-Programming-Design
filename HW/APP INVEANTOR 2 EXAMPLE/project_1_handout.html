專案 1：文字發聲器（會說話的哈囉世界）

學習目標：認識按鈕點擊事件、文字輸入盒，以及呼叫手機內建的「語音合成（TextToSpeech）」模組。

一、 畫面編排（Designer 介面設計）

元件類別元件名稱屬性設定 / 修改說明
使用者介面Label1 (標籤)字體大小 22，文字：「請輸入想讓手機說的話」
使用者介面TextBox1 (輸入盒)寬度：「填滿」，提示文字：「在此輸入文字...」
使用者介面Button1 (按鈕)字體大小 18，形狀：圓角，文字：「點我發音 🔊」
多媒體TextToSpeech1非可視元件，負責將文字轉為真人發聲

二、 程式積木（Blocks 設計步驟）

  • 按鈕事件：從左側 Button1 拉出 when Button1.Click do。
  • 畫面同步：從 Label1 拉出 set Label1.Text to，並接上 TextBox1.Text（將打入的字顯示在標籤上）。
  • 語音朗讀：從 TextToSpeech1 拉出紫色的 call TextToSpeech1.Speak message:，後面接上 TextBox1.Text 即可完成。
