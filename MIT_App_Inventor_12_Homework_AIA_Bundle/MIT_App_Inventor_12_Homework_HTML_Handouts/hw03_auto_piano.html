專案 3 變化題：雙模式小木琴—支援自動播放小星星 (HW03_AutoPiano)

🔗 延伸自：原專案 3：七音階迷你電子琴 ｜ 對應專案檔：HW03_AutoPiano.aia

🎯 變化題設計目標與挑戰

保留原有的 7 個手動彈奏琴鍵（Do ~ Si），額外結合「清單（List）」儲存《小星星》簡譜音檔序列與「計時器（Clock）」循序讀取清單項目，實現點擊「自動播放」即可自動演奏樂曲的功能。

一、 畫面編排與元件屬性表（Designer 設計）

元件名稱 元件類別 屬性設定與功能說明
HorizontalArrangement1水平配置寬度：填滿、高度：180 像素（內含 Btn1 ~ Btn7 共 7 個琴鍵按鈕）
Btn1 ~ Btn7按鈕 (Button)寬度：45 像素、高度：填滿、文字依序為：「Do, Re, Mi, Fa, Sol, La, Si」
HorizontalArrangement2水平配置寬度：填滿、水平對齊：置中（放置自動播放與停止按鈕）
Button_AutoPlay按鈕 (Button)字體大小：16、形狀：圓角、文字：「🎵 自動播放小星星」
Button_StopAuto按鈕 (Button)字體大小：16、形狀：圓角、文字：「⏹️ 停止播放」
Label_Note標籤 (Label)字體大小：18、文字：「目前狀態：手動彈奏或點擊自動播放」
Sound1音效 (Sound)非可視元件；素材區已內建 1.wav ~ 7.wav 七個真實音階檔
Clock1計時器 (Clock)非可視元件；計時器間隔 (TimerInterval)：500 (0.5秒一拍)、計時器啟用：取消打勾 ⬜

二、 程式積木組裝步驟（Blocks 邏輯設計）

  • 步驟 1：建立樂譜清單與索引變數初始化全域變數【song_notes】為清單：["1.wav", "1.wav", "5.wav", "5.wav", "6.wav", "6.wav", "5.wav", "4.wav", "4.wav", "3.wav", "3.wav", "2.wav", "2.wav", "1.wav"]；並初始化【note_idx】為 1。
  • 步驟 2：啟動與停止自動播放當 Button_AutoPlay.被點選：設 global note_idx 為 1，並設 Clock1.TimerEnabled 為 true；當 Button_StopAuto.被點選：設 Clock1.TimerEnabled 為 false。
  • 步驟 3：計時器循序播音邏輯當 Clock1.計時 執行：如果 note_idx <= 清單長度(song_notes)，則設 Sound1.來源 為【選取清單項目(song_notes, note_idx)】，呼叫 Sound1.播放，並將 note_idx 加 1；否則關閉計時器並顯示「演奏完成！」。

三、 積木邏輯虛擬碼對照（Blocks Logic Overview）

initialize global song_notes to list("1.wav","1.wav","5.wav","5.wav","6.wav","6.wav","5.wav","4.wav","4.wav","3.wav","3.wav","2.wav","2.wav","1.wav")
initialize global note_idx to 1

when Button_AutoPlay.Click do
  set global note_idx to 1
  set Clock1.TimerEnabled to true

when Clock1.Timer do
  if (global note_idx <= length of list(global song_notes)) then
    set Sound1.Source to select list item(list: global song_notes, index: global note_idx)
    call Sound1.Play()
    set Label_Note.Text to join("🎵 自動播放小星星：第 ", global note_idx, " 拍")
    set global note_idx to (global note_idx + 1)
  else
    set Clock1.TimerEnabled to false
    set Label_Note.Text to "🎉 小星星自動演奏完成！"
