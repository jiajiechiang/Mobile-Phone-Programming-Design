專案 8 變化題：附近美食地標雷達 (HW08_FoodRadar)

🔗 延伸自：原專案 8：GPS 定位與地圖導航 ｜ 對應專案檔：HW08_FoodRadar.aia

🎯 變化題設計目標與挑戰

在地圖元件中除了顯示使用者自身位置的動態標記（Marker_Me）外，預先建立多個固定美食地標（Marker_Spot1、Marker_Spot2），並透過經緯度絕對值差值運算，當使用者走近美食地標一定範圍內時，自動觸發「已接近名店！」雷達警報。

一、 畫面編排與元件屬性表（Designer 設計）

元件名稱 元件類別 屬性設定與功能說明
Map1地圖 (Map)寬度：填滿、高度：320 像素、縮放級別：15
Marker_Me標記 (Marker)放進 Map1 內；標題：「我的目前位置」
Marker_Spot1標記 (Marker)放進 Map1 內；填充顏色：紅色、緯度：25.033964、經度：121.564468、標題：「人氣小籠包名店」
Marker_Spot2標記 (Marker)放進 Map1 內；填充顏色：藍色、緯度：25.035500、經度：121.566000、標題：「招牌珍珠奶茶店」
Label_GPS標籤 (Label)字體大小：16、文字：「📍 正在定位中...」
Label_Alert標籤 (Label)字體大小：18、粗體：打勾、文字顏色：紅色、文字：「🔔 雷達狀態：搜尋周邊美食中」
LocationSensor1位置感測器非可視元件；時間間隔：5000 (5秒)

二、 程式積木組裝步驟（Blocks 邏輯設計）

  • 步驟 1：更新自身座標與地圖中心當 LocationSensor1.位置改變(latitude, longitude...) 執行：更新 Marker_Me 的經緯度，並呼叫 Map1.PanTo 移動視角。
  • 步驟 2：計算與美食地標的距離差使用數學積木【絕對值 (abs)】計算 `abs(latitude - Marker_Spot1.Latitude)`。
  • 步驟 3：觸發接近警報如果緯度差 `< 0.002`（約 200 公尺內），將 Label_Alert.文字 設為「🎉 叮咚！您已接近【人氣小籠包名店】！」；否則顯示「🚶 持續移動探索周邊美食地標中...」。

三、 積木邏輯虛擬碼對照（Blocks Logic Overview）

when LocationSensor1.LocationChanged(latitude, longitude, altitude, speed) do
  set Marker_Me.Latitude to latitude
  set Marker_Me.Longitude to longitude
  call Map1.PanTo(latitude, longitude, zoom: 16)
  set Label_GPS.Text to join("📍 緯度：", latitude, " / 經度：", longitude)
  if (abs(latitude - Marker_Spot1.Latitude) < 0.002) then
    set Label_Alert.Text to "🎉 叮咚！您已接近【人氣小籠包名店】！"
  else
    set Label_Alert.Text to "🚶 持續移動探索周邊美食地標中..."
