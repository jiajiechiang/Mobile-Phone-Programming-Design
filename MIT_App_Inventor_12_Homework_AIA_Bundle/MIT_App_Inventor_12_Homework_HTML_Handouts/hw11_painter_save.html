專案 11 變化題：小畫家與作品截圖存檔 (HW11_PainterSave)

🔗 延伸自：原專案 11：手繪塗鴉板 ｜ 對應專案檔：HW11_PainterSave.aia

🎯 變化題設計目標與挑戰

在手繪塗鴉板的基礎上，新增「滑動條（Slider）」讓使用者無段調整畫筆線條粗細（1 ~ 30 像素），並加入「💾 存檔」按鈕呼叫畫布的 SaveAs 方法，將創作完成的手繪圖檔直接儲存至手機內部空間。

一、 畫面編排與元件屬性表（Designer 設計）

元件名稱 元件類別 屬性設定與功能說明
HorizontalArrangement_Slider水平配置寬度：填滿、垂直對齊：置中
Label_Size標籤 (Label)字體大小：16、文字：「畫筆粗細：5」
Slider_Size滑動條 (Slider)寬度：填滿、最小值 (MinValue)：1、最大值 (MaxValue)：30、滑塊位置 (ThumbPosition)：5
Canvas1畫布 (Canvas)寬度：填滿、高度：300 像素、背景顏色：白色、線條寬度：5
HorizontalArrangement_Btns水平配置寬度：填滿，內含 Btn_Red（紅筆）、Btn_Blue（藍筆）、Btn_Clear（清除）、Btn_Save（💾 存檔）
Label_Status標籤 (Label)字體大小：14、文字：「狀態：請在畫布上滑動塗鴉」

二、 程式積木組裝步驟（Blocks 邏輯設計）

  • 步驟 1：滑桿動態調整畫筆粗細當 Slider_Size.位置改變 (PositionChanged) 執行：設【Canvas1.線條寬度 (LineWidth)】為 `thumbPosition`，並更新 Label_Size.文字。
  • 步驟 2：拖曳畫線與換色清除保留當 Canvas1.被拖曳 時呼叫 DrawLine(prevX, prevY, currentX, currentY)，以及紅筆、藍筆、清除按鈕事件。
  • 步驟 3：作品另存成 PNG 圖檔當 Btn_Save.被點選 執行：呼叫帶回傳值的【Canvas1.另存新檔 (SaveAs) 檔名："my_art.png"】，並將回傳的檔案儲存路徑顯示在 Label_Status 上。

三、 積木邏輯虛擬碼對照（Blocks Logic Overview）

when Slider_Size.PositionChanged(thumbPosition) do
  set Canvas1.LineWidth to thumbPosition
  set Label_Size.Text to join("畫筆粗細：", thumbPosition)

when Btn_Save.Click do
  set Label_Status.Text to join(
    "✅ 已儲存圖檔至：",
    call Canvas1.SaveAs(fileName: "my_art.png")
  )
