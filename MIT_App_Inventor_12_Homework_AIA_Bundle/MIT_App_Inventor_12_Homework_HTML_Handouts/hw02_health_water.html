專案 2 變化題：理想體重與每日喝水量計算機 (HW02_HealthWater)

🔗 延伸自：原專案 2：BMI 健康體位計算機 ｜ 對應專案檔：HW02_HealthWater.aia

🎯 變化題設計目標與挑戰

除了原有的 BMI 計算外，新增性別下拉選單（男生／女生），根據男女不同公式自動算出「建議理想體重」，並依據個人體重乘以 30 ml 計算出「今日建議喝水量」，學會多變數綜合數學運算。

一、 畫面編排與元件屬性表（Designer 設計）

元件名稱 元件類別 屬性設定與功能說明
Screen1表單 (Form)水平對齊：置中 (Center: 3)、標題：「HW02 理想體重與喝水量」
Spinner_Gender下拉選單 (Spinner)元素字串 (ElementsFromString)：「男生,女生」
TextBox_Height文字輸入盒 (TextBox)寬度：填滿、僅限數字：打勾 ✅、提示：「請輸入身高 (公分)」、預設：「170」
TextBox_Weight文字輸入盒 (TextBox)寬度：填滿、僅限數字：打勾 ✅、提示：「請輸入體重 (公斤)」、預設：「65」
Button_Calc按鈕 (Button)字體大小：18、形狀：圓角、文字：「📊 計算 BMI、理想體重與喝水量」
Label_BMI標籤 (Label)字體大小：18、文字：「BMI 指數：尚未計算」
Label_IdealWeight標籤 (Label)字體大小：18、文字顏色：深綠色、文字：「建議理想體重：尚未計算」
Label_Water標籤 (Label)字體大小：18、文字顏色：藍色、文字：「今日建議喝水量：尚未計算」

二、 程式積木組裝步驟（Blocks 邏輯設計）

  • 步驟 1：宣告全域變數建立兩個全域變數：【初始化全域變數 bmi 為 0】與【初始化全域變數 ideal 為 0】。
  • 步驟 2：計算 BMI 數值當 Button_Calc.被點選時，設全域變數 bmi 為：TextBox_Weight.文字 ÷ ((TextBox_Height.文字 ÷ 100) ^ 2)。
  • 步驟 3：依性別計算理想體重使用 if...else 判斷：若 Spinner_Gender.選取項目 = "男生"，設 global ideal 為 (身高 - 80) × 0.7；否則（女生）設為 (身高 - 70) × 0.6。
  • 步驟 4：計算每日建議喝水量並顯示結果利用【合併文字 (join)】分別更新三個標籤：Label_BMI 顯示 BMI、Label_IdealWeight 顯示理想體重、Label_Water 顯示（體重 × 30）毫升。

三、 積木邏輯虛擬碼對照（Blocks Logic Overview）

initialize global bmi to 0
initialize global ideal to 0

when Button_Calc.Click do
  set global bmi to (TextBox_Weight.Text / ((TextBox_Height.Text / 100) ^ 2))
  if (Spinner_Gender.Selection = "男生") then
    set global ideal to ((TextBox_Height.Text - 80) * 0.7)
  else
    set global ideal to ((TextBox_Height.Text - 70) * 0.6)
  set Label_BMI.Text to join("📊 BMI 指數：", global bmi)
  set Label_IdealWeight.Text to join("⚖️ 建議理想體重：", global ideal, " 公斤 (kg)")
  set Label_Water.Text to join("💧 今日建議喝水量：", (TextBox_Weight.Text * 30), " 毫升 (ml)")
