專案 6 變化題：限時 30 秒打地鼠—含扣分炸彈陷阱 (HW06_BombMole)

🔗 延伸自：原專案 6：進階打地鼠遊戲 ｜ 對應專案檔：HW06_BombMole.aia

🎯 變化題設計目標與挑戰

在畫布上同時放入「地鼠（Sprite_Mole）」與「炸彈（Sprite_Bomb）」兩個影像精靈，並配備雙計時器：一個控制精靈每 0.8 秒隨機瞬移，另一個負責 30 秒遊戲倒數。打中地鼠 +1 分，誤觸炸彈扣 2 分並震動警告！

一、 畫面編排與元件屬性表（Designer 設計）

元件名稱 元件類別 屬性設定與功能說明
HorizontalArrangement1水平配置寬度：填滿、水平對齊：置中（內含得分與剩餘秒數標籤）
Label_Score / Label_Timer標籤 (Label)字體大小：20、粗體：打勾，分別顯示「得分：0」與「剩餘：30秒」
Canvas1畫布 (Canvas)寬度：填滿、高度：330 像素、背景顏色：綠色
Sprite_Mole影像精靈 (ImageSprite)放進 Canvas1 內；圖片：mole.png、寬高：60x60 像素
Sprite_Bomb影像精靈 (ImageSprite)放進 Canvas1 內；圖片：bomb.png、寬高：60x60 像素
Btn_Restart按鈕 (Button)字體大小：16、形狀：圓角、文字：「🔄 重新開始 30 秒挑戰」
Clock_Move / Clock_Countdown計時器 (Clock)兩個計時器：Clock_Move 間隔 800ms（控制移動），Clock_Countdown 間隔 1000ms（控制 30 秒倒數）
Sound1音效 (Sound)非可視元件，誤觸炸彈時震動手機

二、 程式積木組裝步驟（Blocks 邏輯設計）

  • 步驟 1：雙精靈隨機移動當 Clock_Move.計時 執行：分別呼叫 Sprite_Mole.移動到 與 Sprite_Bomb.移動到 隨機座標 (X: 0~240, Y: 0~260)。
  • 步驟 2：打中地鼠加分 vs 誤觸炸彈扣分當 Sprite_Mole.被觸碰：global score 加 1 並更新分數標籤；當 Sprite_Bomb.被觸碰：global score 減 2、呼叫 Sound1.震動(300) 並顯示誤觸警告。
  • 步驟 3：30 秒遊戲限時機制當 Clock_Countdown.計時 執行：若 time_left > 0 則減 1；否則將 Clock_Move 與 Clock_Countdown 的 TimerEnabled 皆設為 false，停止遊戲。

三、 積木邏輯虛擬碼對照（Blocks Logic Overview）

when Sprite_Mole.Touched do
  set global score to (global score + 1)
  set Label_Score.Text to join("得分：", global score)

when Sprite_Bomb.Touched do
  set global score to (global score - 2)
  call Sound1.Vibrate(millisecs: 300)
  set Label_Score.Text to join("💥 誤觸炸彈！得分：", global score)

when Clock_Countdown.Timer do
  if (global time_left > 0) then
    set global time_left to (global time_left - 1)
    set Label_Timer.Text to join("  剩餘：", global time_left, "秒")
  else
    set Clock_Move.TimerEnabled to false
    set Clock_Countdown.TimerEnabled to false
    set Label_Timer.Text to "  ⏰ 時間到！遊戲結束"
