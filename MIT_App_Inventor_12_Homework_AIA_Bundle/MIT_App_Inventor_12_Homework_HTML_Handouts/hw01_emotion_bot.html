專案 1 變化題：情緒對話機器人 (HW01_EmotionBot)

🔗 延伸自：原專案 1：文字發聲器（輸入文字後朗讀） ｜ 對應專案檔：HW01_EmotionBot.aia

🎯 變化題設計目標與挑戰

在原有文字發聲器的基礎上，加入「下拉選單（Spinner）」提供多種情緒模式（開心、生氣、慢速低沉），並利用 조건判斷（if...else if...else）動態調整語音合成元件的「音調（Pitch）」與「語速（SpeechRate）」，打造出具有情緒表現力的對話機器人。

一、 畫面編排與元件屬性表（Designer 設計）

元件名稱 元件類別 屬性設定與功能說明
Screen1表單 (Form)水平對齊：置中 (Center: 3)、標題：「HW01 情緒對話機器人」
Label_Title標籤 (Label)字體粗體：打勾、字體大小：20、文字：「🤖 請選擇機器人情緒與輸入台詞」
Spinner_Emotion下拉選單 (Spinner)元素字串 (ElementsFromString)：「開心,生氣,慢速低沉」（以半形逗號分隔）
TextBox_Msg文字輸入盒 (TextBox)寬度：填滿 (Fill parent)、提示：「在此輸入想讓機器人說的話...」、預設文字：「哈囉！很高興認識你！」
Button_Speak按鈕 (Button)字體大小：18、形狀：圓角 (rounded)、文字：「🔊 依情緒發音」
Label_Status標籤 (Label)字體大小：16、文字顏色：藍色、文字：「目前狀態：待命」
TextToSpeech1語音合成 (TextToSpeech)非可視元件（拖入畫面後顯示於下方非可視元件區）

二、 程式積木組裝步驟（Blocks 邏輯設計）

  • 步驟 1：建立按鈕點擊事件從左側「Button_Speak」拉出【當 Button_Speak.被點選 執行】(when Button_Speak.Click do) 褐黃色事件積木。
  • 步驟 2：加入多條件邏輯判斷從「控制 (Control)」拉出【如果...那麼...否則如果...否則】(if / else if / else) 積木放入事件內。
  • 步驟 3：設定「開心」情緒參數第一層條件判斷【Spinner_Emotion.選取項目 = "開心"】：設定 TextToSpeech1.音調 (Pitch) 為 1.5（高亢）、語速 (SpeechRate) 為 1.3（輕快），並將 Label_Status.文字 設為「😊 開心語氣發音中」。
  • 步驟 4：設定「生氣」與「慢速低沉」參數第二層條件判斷【Spinner_Emotion.選取項目 = "生氣"】：設定 Pitch 為 0.6（低沉）、SpeechRate 為 1.2；否則（即慢速低沉）設定 Pitch 為 0.8、SpeechRate 為 0.6。
  • 步驟 5：呼叫語音朗讀在 if 判斷積木正下方，接上紫色的【呼叫 TextToSpeech1.發音 訊息】，並將【TextBox_Msg.文字】嵌入訊息缺口中。

三、 積木邏輯虛擬碼對照（Blocks Logic Overview）

when Button_Speak.Click do
  if (Spinner_Emotion.Selection = "開心") then
    set TextToSpeech1.Pitch to 1.5
    set TextToSpeech1.SpeechRate to 1.3
    set Label_Status.Text to "😊 開心語氣發音中 (高音調+快語速)"
  else if (Spinner_Emotion.Selection = "生氣") then
    set TextToSpeech1.Pitch to 0.6
    set TextToSpeech1.SpeechRate to 1.2
    set Label_Status.Text to "😠 生氣語氣發音中 (低沉音調)"
  else
    set TextToSpeech1.Pitch to 0.8
    set TextToSpeech1.SpeechRate to 0.6
    set Label_Status.Text to "🐢 慢速低沉機器人發音中"
  call TextToSpeech1.Speak(message: TextBox_Msg.Text)
