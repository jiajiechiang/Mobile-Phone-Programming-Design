專案 12 變化題：拍立得相框紀念照合成器 (HW12_PolaroidCamera)

🔗 延伸自：原專案 12：隨身快拍與相簿存取 ｜ 對應專案檔：HW12_PolaroidCamera.aia

🎯 變化題設計目標與挑戰

利用白色背景的「垂直配置（VerticalArrangement）」設計出經典的拍立得（Polaroid）留白相框視覺效果，拍照或選圖後不僅能顯示在相框中央，還會透過 Clock 元件自動抓出當下拍攝的年月日時分，並支援自訂心情小語題字！

一、 畫面編排與元件屬性表（Designer 設計）

元件名稱 元件類別 屬性設定與功能說明
Screen1表單 (Form)背景顏色：淺灰色 (&HFFEEEEEE)、水平對齊：置中、標題：「HW12 拍立得相框合成器」
VerticalArrangement_Polaroid垂直配置背景顏色：純白色（形成拍立得白邊外框）、寬度：280 像素、水平對齊：置中
Image1圖像 (Image)放進白色拍立得框內；寬度：240 像素、高度：240 像素
Label_Caption標籤 (Label)放進白色拍立得框內；字體大小：18、粗體：打勾、文字：「✨ 今日美好時光紀念」
Label_Date標籤 (Label)放進白色拍立得框內；字體大小：14、文字顏色：深灰、文字：「📅 拍攝日期：尚未拍攝」
HorizontalArrangement1水平配置寬度：填滿，內含 TextBox_Mood（輸入拍立得心情小語）與 Btn_SetMood（✍️ 更新題字）
HorizontalArrangement2水平配置寬度：填滿，內含 Button_Camera（📷 拍照合成）與 ImagePicker1（🖼️ 相簿選圖）
Camera1 / Clock1相機 / 計時器非可視元件；Camera1 負責拍照，Clock1 負責取得系統當前時間並格式化為日期字串

二、 程式積木組裝步驟（Blocks 邏輯設計）

  • 步驟 1：拍照並自動印上時間戳記當 Camera1.拍照完成 (AfterPicture) 執行：設 Image1.圖片 為 `image`，並設 Label_Date.文字 為【呼叫 Clock1.FormatDateTime(instant: 呼叫 Clock1.Now(), pattern: "yyyy/MM/dd HH:mm")】。
  • 步驟 2：更新拍立得下方心情題字當 Btn_SetMood.被點選 執行：設 Label_Caption.文字 為合併文字 `"✨ " + TextBox_Mood.文字`。
  • 步驟 3：支援相簿選圖套用相框當 ImagePicker1.選擇後 執行：設 Image1.圖片 為 ImagePicker1.Selection。

三、 積木邏輯虛擬碼對照（Blocks Logic Overview）

when Camera1.AfterPicture(image) do
  set Image1.Picture to image
  set Label_Date.Text to join(
    "📅 拍攝時間：",
    call Clock1.FormatDateTime(instant: call Clock1.Now(), pattern: "yyyy/MM/dd HH:mm")
  )

when Btn_SetMood.Click do
  set Label_Caption.Text to join("✨ ", TextBox_Mood.Text)
