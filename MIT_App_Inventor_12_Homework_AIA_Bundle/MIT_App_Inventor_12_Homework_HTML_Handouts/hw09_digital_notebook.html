專案 9 變化題：多功能個人數位筆記本 (HW09_DigitalNotebook)

🔗 延伸自：原專案 9：多畫面切換生活小幫手 ｜ 對應專案檔：HW09_DigitalNotebook.aia

🎯 變化題設計目標與挑戰

完整實作三畫面（Screen1 導覽首頁、Screen2 記帳累加小工具、Screen3 動態待辦事項清單）的真實互動邏輯，不再只是空白頁面跳轉，而是讓每個子畫面都具備獨立的資料處理功能！

一、 畫面編排與元件屬性表（Designer 設計）

元件名稱 元件類別 屬性設定與功能說明
Screen1 (首頁)表單 (Form)包含標題 Label_Title、按鈕 Btn_GoScreen2（💰 進入記帳小工具）與 Btn_GoScreen3（📝 進入待辦事項清單）
Screen2 (記帳頁)表單 (Form)包含數字輸入框 TextBox_Amount、按鈕 Btn_Add（➕ 新增一筆支出）、總計標籤 Label_Total 與返回按鈕 Btn_Back1
Screen3 (待辦頁)表單 (Form)包含文字輸入框 TextBox_Todo、按鈕 Btn_AddTodo（➕ 加入待辦清單）、清單檢視器 ListView1 與返回按鈕 Btn_Back2

二、 程式積木組裝步驟（Blocks 邏輯設計）

  • 步驟 1：Screen1 首頁導覽積木點擊 Btn_GoScreen2 呼叫【開啟另一個畫面 "Screen2"】；點擊 Btn_GoScreen3 呼叫【開啟另一個畫面 "Screen3"】。
  • 步驟 2：Screen2 記帳累加邏輯宣告全域變數 `total = 0`。當點擊 Btn_Add 時，將 `global total` 設為 `global total + TextBox_Amount.文字`，並即時更新於 Label_Total 上。
  • 步驟 3：Screen3 待辦清單邏輯宣告全域空清單 `todo_list`。當點擊 Btn_AddTodo 時，使用【新增清單項目 (add items to list)】將 TextBox_Todo.文字 加入 `todo_list`，並設 `ListView1.元素 (Elements)` 為 `global todo_list`。

三、 積木邏輯虛擬碼對照（Blocks Logic Overview）

// --- Screen2 (記帳小工具) ---
initialize global total to 0
when Btn_Add.Click do
  set global total to (global total + TextBox_Amount.Text)
  set Label_Total.Text to join("目前累積總支出：", global total, " 元")

// --- Screen3 (待辦事項清單) ---
initialize global todo_list to create empty list
when Btn_AddTodo.Click do
  add items to list(list: global todo_list, item: TextBox_Todo.Text)
  set ListView1.Elements to global todo_list
