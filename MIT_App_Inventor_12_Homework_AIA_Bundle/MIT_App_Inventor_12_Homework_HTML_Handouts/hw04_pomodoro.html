專案 4 變化題：健身／讀書專用番茄鐘 (HW04_Pomodoro)

🔗 延伸自：原專案 4：碼錶倒數計時器 ｜ 對應專案檔：HW04_Pomodoro.aia

🎯 變化題設計目標與挑戰

將單純的倒數計時器升級為雙階段「番茄工作法（Pomodoro）」計時器：支援一鍵啟動「專注 25 分鐘（1500 秒）」與「休息 5 分鐘（300 秒）」，且當專注倒數歸零時，手機會自動震動並無縫切換至 5 分鐘休息倒數！

一、 畫面編排與元件屬性表（Designer 設計）

元件名稱 元件類別 屬性設定與功能說明
Label_Mode標籤 (Label)字體大小：24、粗體：打勾、文字顏色：紅色、文字：「🍅 番茄鐘模式：準備開始」
Label_Time標籤 (Label)字體大小：60、粗體：打勾、文字：「1500」
HorizontalArrangement1水平配置寬度：填滿、水平對齊：置中
Btn_Work / Btn_Rest / Btn_Stop按鈕 (Button)放進水平配置內，文字分別為：「🔥 專注25分」、「☕ 休息5分」、「⏸️ 暫停」
Clock1計時器 (Clock)計時器間隔：1000 (1秒)、計時器啟用：取消打勾 ⬜
Sound1音效 (Sound)非可視元件，用於階段切換時觸發手機震動提醒

二、 程式積木組裝步驟（Blocks 邏輯設計）

  • 步驟 1：建立狀態布林變數初始化全域變數【is_work】為 true（真代表專注模式，假代表休息模式）。
  • 步驟 2：設定專注與休息按鈕點擊 Btn_Work 時：設 is_work 為 true、Label_Time.文字 設為 1500、啟動 Clock1；點擊 Btn_Rest 時：設 is_work 為 false、Label_Time.文字 設為 300、啟動 Clock1。
  • 步驟 3：倒數與自動切換階段當 Clock1.計時 執行：若 Label_Time.文字 > 0 則每秒減 1；否則呼叫 Sound1.震動(800)，接著檢查若 is_work 為 true，自動將 is_work 改為 false、Label_Time 重設為 300 並顯示「☕ 自動進入 5 分鐘休息」；若休息也結束則停止計時。

三、 積木邏輯虛擬碼對照（Blocks Logic Overview）

initialize global is_work to true

when Clock1.Timer do
  if (Label_Time.Text > 0) then
    set Label_Time.Text to (Label_Time.Text - 1)
  else
    call Sound1.Vibrate(millisecs: 800)
    if (global is_work) then
      set global is_work to false
      set Label_Mode.Text to "☕ 專注完成！自動進入 5 分鐘休息"
      set Label_Time.Text to 300
    else
      set Clock1.TimerEnabled to false
      set Label_Mode.Text to "🎉 恭喜完成一輪番茄鐘循環！"
